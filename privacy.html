개인정보처리방침

최종 수정일: 2024년 1월

FunTest(이하 "서비스")는 사용자의 개인정보 보호를 매우 중요하게 생각합니다. 본 개인정보처리방침은 서비스가 사용자의 정보를 어떻게 수집, 사용, 공개, 보호하는지 설명합니다.

1. 수집하는 정보

서비스는 다음과 같은 정보를 수집할 수 있습니다:

  • 문의 양식 정보: 이름, 이메일 주소, 문의 내용 (문의하기 기능 사용 시)
  • 자동 수집 정보: IP 주소, 브라우저 유형, 방문 시간, 페이지 조회 기록 (웹 분석 목적)

2. 이미지 데이터 처리

동물상 테스트에서 사용되는 이미지는 다음과 같이 처리됩니다:

  • 모든 이미지 분석은 사용자의 브라우저에서 직접 수행됩니다 (클라이언트 사이드 처리).
  • 이미지는 서버로 전송되거나 저장되지 않습니다.
  • 분석이 완료되면 이미지 데이터는 브라우저 메모리에서 자동으로 삭제됩니다.
  • 웹캠 스트림은 분석 목적으로만 사용되며 녹화되지 않습니다.

3. 정보 사용 목적

수집된 정보는 다음 목적으로 사용됩니다:

  • 서비스 제공 및 유지
  • 사용자 문의에 대한 응답
  • 서비스 개선 및 새로운 기능 개발
  • 서비스 이용 현황 분석

4. 정보 공유

서비스는 다음 경우를 제외하고 사용자의 개인정보를 제3자와 공유하지 않습니다:

  • 사용자의 동의가 있는 경우
  • 법적 요구가 있는 경우
  • 서비스 제공을 위해 필요한 경우 (예: 이메일 발송 서비스)

5. 쿠키 및 추적 기술

서비스는 다음과 같은 목적으로 쿠키를 사용할 수 있습니다:

  • 사용자 환경설정 저장 (언어 선택 등)
  • 서비스 이용 통계 분석 (Google Analytics)
  • 광고 제공 (Google AdSense)

6. 제3자 서비스

서비스는 다음과 같은 제3자 서비스를 사용합니다:

  • Google AdSense: 광고 제공
  • Google Analytics: 웹사이트 분석
  • Formspree: 문의 양식 처리
  • TensorFlow.js: 이미지 분석 (클라이언트 사이드)

7. 정보 보안

서비스는 사용자 정보를 보호하기 위해 다음과 같은 조치를 취합니다:

  • HTTPS를 통한 암호화된 데이터 전송
  • 클라이언트 사이드 이미지 처리로 서버 저장 방지
  • 정기적인 보안 검토

8. 문의

개인정보처리방침에 관한 문의사항이 있으시면 문의하기 페이지를 통해 연락해주세요.

Privacy Policy

Last Updated: January 2024

FunTest ("Service") takes your privacy very seriously. This Privacy Policy explains how we collect, use, disclose, and protect your information.

1. Information We Collect

The Service may collect the following information:

  • Contact Form Information: Name, email address, message content (when using the contact feature)
  • Automatically Collected Information: IP address, browser type, visit time, page views (for web analytics)

2. Image Data Processing

Images used in the Animal Type Test are processed as follows:

  • All image analysis is performed directly in your browser (client-side processing).
  • Images are not sent to or stored on any server.
  • Image data is automatically deleted from browser memory after analysis.
  • Webcam streams are used only for analysis purposes and are not recorded.

3. How We Use Information

Collected information is used for:

  • Providing and maintaining the Service
  • Responding to user inquiries
  • Improving the Service and developing new features
  • Analyzing Service usage

4. Information Sharing

We do not share your personal information with third parties except:

  • With your consent
  • When required by law
  • When necessary for service provision (e.g., email services)

5. Cookies and Tracking

The Service may use cookies for:

  • Saving user preferences (language selection, etc.)
  • Usage analytics (Google Analytics)
  • Advertising (Google AdSense)

6. Third-Party Services

The Service uses the following third-party services:

  • Google AdSense: Advertising
  • Google Analytics: Website analytics
  • Formspree: Contact form processing
  • TensorFlow.js: Image analysis (client-side)

7. Security

We protect your information through:

  • Encrypted data transmission via HTTPS
  • Client-side image processing to prevent server storage
  • Regular security reviews

8. Contact

If you have questions about this Privacy Policy, please contact us.
